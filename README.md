# 📊 eCommerce Sales Data Analysis using Python

## 📌 Project Overview

This project focuses on analyzing an eCommerce store’s sales data using Python. The goal is to clean raw transactional data, perform exploratory data analysis (EDA), and generate meaningful business insights through visualizations.

The analysis helps understand **customer behavior, sales performance, geographic trends, and channel-wise contribution**, making it useful for data analytics and business decision-making.

---

## 🛠️ Tools & Technologies Used

* **Python**
* **Pandas** – data loading, cleaning, transformation
* **Matplotlib** – basic plotting
* **Seaborn** – advanced and aesthetic visualizations
* **Excel Dataset** – source of raw eCommerce data

---

## 🧹 Data Cleaning & Preprocessing

The raw dataset contained inconsistencies and unstructured values. Key cleaning steps included:

* Standardizing **gender values** for consistency
* Converting **text-based quantities** into numeric values
* Normalizing **city and state names**
* Creating meaningful **age groups** for customer segmentation
* Converting date columns into proper datetime format
* Extracting **month information** for time-based analysis
* Categorizing transactions into **B2B and B2C business types**

These steps ensured accurate analysis and reliable insights.

---

## 📈 Exploratory Data Analysis (EDA)

After cleaning, the dataset was explored to understand sales patterns and trends across different dimensions:

* Gender-wise sales and order distribution
* Order status distribution
* Top-performing states and cities by total sales
* Sales contribution across different age groups
* Channel-wise sales contribution
* Category-wise sales performance
* Comparison between **B2B and B2C transactions**

Visualization techniques were used to clearly communicate trends and patterns.

---

## 🔍 Key Insights Generated

* Identified which **customer segments** contribute the most revenue
* Discovered **top-selling regions and cities**
* Analyzed **sales dominance by age group and gender**
* Evaluated the performance of **sales channels and product categories**
* Compared **B2B vs B2C** contribution to overall revenue

These insights can help businesses improve targeting, marketing strategies, and inventory planning.
